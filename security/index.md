# 🛡️ Seguridad y Autenticación

Índice de los protocolos de seguridad implementados en el proyecto. Este apartado describe cómo se protege la API y el acceso a los datos.

- [Política de JWT](./jwt_policy.md) - Explicación de la autenticación mediante JSON Web Tokens de Supabase Auth.
- [Modelo de Roles (RBAC)](./role_model.md) - Definición de roles (USER, TRAINER, ADMIN) y sus permisos en la plataforma.
- [Límites de Peticiones (Rate Limiting)](./rate_limiting.md) - Políticas establecidas para prevenir abusos a la API.
- [Contrato de Errores](./error_contract.md) - Estándares para el reporte seguro de errores sin comprometer la infraestructura interna.
